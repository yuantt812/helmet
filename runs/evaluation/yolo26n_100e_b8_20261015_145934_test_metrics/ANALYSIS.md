## 收敛与泛化

验证集 mAP50–95 从第 1 轮 55.64% 提升到第 20 轮 64.20%、第 60 轮 67.41%。第 80 轮为 67.19%，后 20 轮未获得新的最佳值。训练损失继续下降，验证损失大体持平；模型进入平台期，没有明显的验证性能持续崩落，无法据此断言严重过拟合。继续增加相同配置下的轮数没有已验证的收益。

best.pt 训练结束后的验证结果约为 mAP50=96.78%、mAP50–95=67.42%；独立测试分别为 96.51%、67.15%，均下降约 0.27 个百分点。两者接近，支持模型在当前划分上的效果较稳定。数据相似分组无法保证发现所有同场景图片，这限制了对全新工地泛化能力的推断。

## 定位精度

| 匹配 IoU | 两类平均 AP |
| --- | ---: |
| 0.50 | 96.51% |
| 0.75 | 80.07% |
| 0.80 | 63.87% |
| 0.85 | 41.48% |
| 0.90 | 14.57% |
| 0.95 | 0.57% |

高 IoU 阈值下 AP 明显下降，是 AP50 与 AP50–95 差距的直接证据。目标通常能被找到，但预测框与标注框的高度一致性不足。小目标像素误差和已观察到的标注范围差异是可能原因；没有进行按目标尺寸分层的定量评价，不能认定其中哪个占主导。

## 安全监测关注点

未戴帽类 Precision=92.55%、Recall=90.54%，都低于戴帽类；框架统计点下仍有约 9.46% 的未戴帽目标未被正确检出。类别框数约 2.95:1 的不均衡可能有影响，但不是已确认原因。AP50–95 两类均约 67%，严格定位问题并非只发生在未戴帽类别。

已有混淆矩阵使用 conf=0.001、匹配 IoU=0.45，会纳入大量低置信度预测，和上表 P/R 的统计点不同；不能用其中的背景误检数直接评判实际报警频率。实际报警分析应固定验证集选择的阈值，再统计漏检和误检。

## 收尾完成情况与后续改进

先根据验证集选择演示阈值。验证集最佳权重的 F1 图显示宏平均 F1 峰值约 0.93，对应置信度约 0.504，可作为追求平衡的候选；如果更关注漏报，应在验证集检查较低阈值的未戴帽类召回率和误报数量，不能直接宣称降低阈值一定满足业务要求。

整理小目标、遮挡、逆光、普通帽子和手持安全帽的失败案例，区分漏检、分类错误、框不准和原始标注问题；当前未完成全量按场景或尺寸分层的错误统计。演示视频也需要独立素材，不能把无标注视频的观感作为定量准确率。若后续据测试结果修改数据或训练，应如实说明测试集已经被使用，并准备新的留出数据评估改进。

## 类别和标注处理

原 `helmet` 映射为 `0 helmet`，原 `head` 映射为 `1 no_helmet`，不使用 `person` 和父类 `Workers` 作为训练类别。标注由 COCO 左上角和宽高转换为 YOLO 归一化中心点和宽高，保留九位小数。图片保持原始尺寸与字节，不提前拉伸或压缩。

先用种子 42 抽取 100 张图片进行视觉检查，并放大核对可疑样例；又检查了初版输出的 60 张标签预览及 20 对相似图片。发现普通帽子难辨、同一目标多个框或可见头部漏标的样例时，排除整张图片，未猜测补标。共排除 9 张，逐张原因见 `audit/manual_review.json` 和 `audit/excluded.json`。原始图片和标注均未修改。

抽查支持 `head` 表示未戴安全帽头部的映射，但这属于抽样核对，不是全量人工复标。随机抽样未覆盖到足够明确的手持或放置安全帽案例，不能声称该场景已经验证。原始框有时同时覆盖安全帽和面部，这一框范围沿用原标注。

## 重复与相似场景分组

- 对所有图片解码后计算包含尺寸的 RGB 像素 SHA256，检查完全重复。
- 在 32×32 灰度缩略图上计算 63 位 pHash，在 9×8 灰度图上计算 64 位 dHash。
- 穷举保留图片的所有两两组合：pHash 汉明距离不大于 12，且 dHash 距离不大于 16 时，作为相似候选连接；按连通分量分组。
- 共得到 233 对候选，其中 78 对位于原始数据的不同集合。人工抽看低距离与阈值附近的各 10 对：多数是同图不同水印、裁剪或相邻拍摄；也存在无关图片被保守归入同组的情况。
- 另外将抽样中确认属于同一电杆作业场景、视角不同的两张图片手动归组。
- 最终得到 6809 组，最大组 4 张。按组分配，同时尽量平衡图片数和两类框数；同一组整体进入一个集合。

这能阻止已识别的相似图片跨集合。由于原始数据没有可靠的视频 ID、拍摄批次或场景 ID，哈希方法可能遗漏视角或构图差异大的同场景图片，不能保证所有相关场景均已识别。原文件中的数字序号不被假定为视频帧号。

## 验证

对全部 7026 张导出图片和标签逐一检查：图片字节与原图一致；图片和标签一一配对；类别仅有 0、1；坐标有限、宽高为正且不越界；转换结果与原 COCO 目标框一致；已识别的相似候选、组和像素哈希均未跨集合。结果保存在 `audit/verification.json`。

最终从各集合再抽取 20 张，使用导出的 YOLO 标签反算像素框进行视觉检查，预览为 `audit/exported_train.jpg`、`audit/exported_val.jpg` 和 `audit/exported_test.jpg`。该检查确认转换与绘框位置，不代表原数据所有语义错误已经消除。

## 数据增强

本阶段未生成离线增强图片。训练时按实验方案使用所选 Ultralytics 版本的默认在线增强，并保存实际解析后的参数；验证与测试不使用随机训练增强。640×640 尺寸适配与归一化交给模型的数据加载流程，不改写原图。

## 复现

在项目根目录运行，所有依赖安装到项目 `.venv`：

```bash
python -m pip install -r requirements-preprocess.txt
.venv/bin/python scripts/prepare_dataset.py audit
.venv/bin/python scripts/prepare_dataset.py prepare
.venv/bin/python scripts/prepare_dataset.py verify
```

`prepare` 读取已保留的 `audit/manual_review.json`，重用人工排除和场景归组决定。为防止覆盖已有结果，它要求 `yolo/` 不存在；重新生成前应先将已有输出移至备份目录。`audit` 会重建机器检查结果和抽样预览，不会覆盖人工审查决定。

环境锁定文件：项目根目录的 `requirements-preprocess.txt`，当前为 numpy 2.5.4 和 Pillow 12.3.0，Python 3.12.14。脚本只使用这两个第三方包和标准库，没有安装到系统 Python。

原始下载文件和压缩包哈希：`manifest.json`，其中 ZIP 已在目录清理时删除，解压后的原始文件继续保留在本地。Git 仓库不包含原始数据、生成的 YOLO 数据、`audit/records.json` 和图片预览；新克隆项目先按 [README](README.md#恢复数据与重新生成划分) 恢复原始数据，再执行 `audit` 生成机器记录。审查决定、处理后的划分清单 `audit/split_manifest.json`、相似候选 `audit/near_duplicate_pairs.json`、组 `audit/group_members.json` 及汇总 `audit/summary.json` 均纳入版本控制。
